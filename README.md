# DRILL-14 새의 비행 애니메이션

수업용 `LEC16_Time/bird_animation.png`의 원본으로 새 10마리가 화면을 좌우로 오가는 Pico2D 실습입니다.

## 실행

Python과 Pico2D가 설치된 환경에서 저장소 폴더를 열고 실행합니다. 개발 환경은 Python 3.13과 Pico2D 1.5.1입니다.

```powershell
python main.py
```

800×480 창에서 별도 조작 없이 비행을 볼 수 있습니다. Esc 또는 창 닫기 버튼으로 종료합니다. 이미지 파일은 `main.py`와 같은 폴더에 둡니다.

## 관찰할 동작

- 두 줄에 다섯 마리씩 표시됩니다. 각 새는 다른 날갯짓 단계에서 시작합니다.
- 원본의 14장 자세를 행 순서대로 반복합니다. 그림의 눈 높이를 기준으로 프레임을 정렬해 몸통 높이를 유지합니다.
- 새떼가 창의 좌우 경계 안에서 방향을 바꾸고, 왼쪽으로 날 때 같은 프레임을 좌우 반전합니다.
- 움직임과 날갯짓은 실제 경과 시간을 기준으로 진행합니다.

상세한 구현 근거는 마지막 커밋 본문과 `PRE_PRD.md`에서 확인할 수 있습니다. 원본 시트 분석, 비행 로직 작성, 문서화에 AI를 활용했습니다.
