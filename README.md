# DRILL-14 새의 비행 애니메이션

LEC16_Time의 게임 프레임워크와 기존 캐릭터가 있는 장면에 새 10마리의 비행을 추가한 Pico2D 실습입니다. 새 스프라이트는 수업 폴더의 `bird_animation.png` 원본을 사용합니다.

## 실행

Python, Pico2D, transitions가 설치된 수업 환경에서 실행합니다. 확인에 사용한 버전은 Python 3.13, Pico2D 1.5.1, transitions 0.9.3입니다.

```powershell
python main.py
```

1600×600 창에서 새들이 자동으로 비행합니다. 기존 캐릭터는 좌우 화살표로 이동하고 Space로 공을 발사합니다. Esc 또는 창 닫기 버튼으로 종료합니다.

## 확인할 동작

- 새 10마리를 두 줄에 다섯 마리씩 표시합니다. 각 새의 날갯짓 시작 위상은 조금씩 다릅니다.
- 원본 시트의 14개 프레임을 위에서 아래로, 각 행에서는 왼쪽에서 오른쪽으로 반복합니다. 프레임별 눈 높이를 정렬해 날갯짓 중 몸통이 튀어 보이는 현상을 줄였습니다.
- 편대 전체가 화면 안에서 좌우를 오가며, 왼쪽으로 날 때 프레임을 좌우 반전합니다.
- LEC16의 `game_framework.frame_time`으로 비행 거리와 날갯짓 프레임을 계산합니다.

원본 시트 분석, 비행 로직 구현, 문서화에 AI를 활용했습니다. 요구사항은 `PRE_PRD.md`, 상세 구현 근거는 마지막 커밋 본문에 있습니다.
